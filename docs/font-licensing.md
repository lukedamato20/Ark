# Bundled font licensing

Ark uses native platform UI fonts first and bundles **Inter Variable** only as the Linux/missing-platform-font fallback through `@fontsource-variable/inter`. Inter is Copyright 2016 The Inter Project Authors and is distributed under the SIL Open Font License 1.1. The complete licence is shipped by the dependency at `node_modules/@fontsource-variable/inter/LICENSE` and is included by Ark's generated third-party notices/supply-chain process.

Ark does not redistribute San Francisco, Segoe UI, Cascadia, Menlo, Consolas, or other proprietary platform fonts. Those names are local system fallbacks only.
